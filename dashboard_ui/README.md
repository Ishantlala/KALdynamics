# Operator Console Blueprint (React + TypeScript)

Planned 24-hour MVP interface views:
1. **Live Telemetry Replay:** Real-time vibration, temperature, pressure, and current charts with edge anomaly markers.
2. **RUL Risk Board:** Prioritized list of factory assets sorted by predicted Remaining Useful Life.
3. **RBAC Approval Queue:** One-click review cards showing drafted CMMS work orders, spare-part inventory status, PR drafts, and attached safety SOP checklists.
4. **Audit Trail:** Immutable log of every anomaly flag, MCP tool invocation, and engineer sign-off.
